TL;DR

flow qc reviews the tasks used to train and evaluate models before an expert has to. Getting a model to find problems was easy. Getting it to stop reporting problems that are not there was the real work.

  • In production, 83% of tasks that fail a check are revised by their expert, and the median fix lands 18 minutes later.
  • A model told to look for errors will report errors. So every finding has to cite evidence: the expert's worked solution and sources, probes run in a sandbox, and the exact lines it inspected.
  • We measure both kinds of error on paired tasks, an expert-verified original and a copy with one planted defect.
  • Every adjudicated expert correction becomes two tests: a case the flow qc agent must now pass, and a near-twin it must still flag. A fix cannot win by going quiet.
  • We tune the flow qc agent's instructions for each project offline with GEPA. A change ships only if it wins on tasks it never saw.
